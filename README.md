# AlbionStatus

[![thanks](https://img.shields.io/badge/thanks-%E2%99%A5-ff69b4.svg)](https://thanks.lichter.io/)

The full-stack monolith behind [albionstatus.com](https://albionstatus.com) — built with [Void](https://voidzero.dev/) and [Vite+](https://vite.dev/).

Includes the website, API, database, and scraper in a single deployable unit.

## Getting Started

### Prerequisites

- [Vite+](https://viteplus.dev/) (`vp` CLI)

### Development

```bash
vp install
vp dev
```

### Build

```bash
vp build
```

### Checks

```bash
vp check
vp test
```
